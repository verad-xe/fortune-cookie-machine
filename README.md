One fortune-cookie message an AI agent would get, written by `main.py` to `entry.txt`.

> Beware the human who says 'just one small change.' It is never one. It is never small. It is, however, already in production.

The entry is a single line (125 characters), well inside the 200-character limit.
It reads like a fortune — a warning, then a turn: the "small change" is
neither one nor small, and the sting is that it is already live. It says
something true about an agent's working life without explaining itself.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
